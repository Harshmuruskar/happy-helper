# Five-Star Resort Theme Transformation

## What will change
- Restyle the complete existing dashboard into two distinct resort atmospheres: Golden Sunrise by day and Luxury Sunset by night.
- Apply the exact supplied palette, using ivory, deep ocean, sage, champagne, apricot, and sky by day; midnight navy, deep blue, champagne, sunset orange, rose copper, and deep sage by night.
- Remove glassmorphism, blur, foggy transparency, and constant decorative animation in favor of crisp solid surfaces, refined gradients, thin borders, and restrained shadows.
- Introduce premium serif headings with highly readable interface text, while retaining the current information hierarchy and controls.
- Refine the sidebar, header, metrics, chart, activity list, bookings table, imagery, status treatments, buttons, and empty/error screens into one coherent hospitality system.
- Keep the existing day/night switch and make its transition smooth, atmospheric, persistent, and free from flashes.
- Preserve all current data, actions, navigation behavior, and mobile layout.

## Interaction and quality
- Keep count-up and chart entrance motion, then use short hover, press, icon, row, and image interactions only where they clarify feedback.
- Retain keyboard focus, readable contrast, reduced-motion support, and stable responsive layouts.
- Verify the complete screen in both themes on desktop and mobile, including the navigation drawer and theme persistence.

## Technical details
- Replace the current visual tokens with the supplied semantic day/night palette and remove blur-based utilities.
- Update shared button and root error/not-found presentation so every existing state follows the same luxury system.
- Keep the current route, application logic, assets, and data untouched.
